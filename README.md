# AI Money Command Center

A responsive, retro-sci-fi command dashboard prototype for a guarded, multi-department business operations system.

## Run locally

Open `index.html` in a browser. This is a static, dependency-free frontend suitable for GitHub Pages.

## Included

- Neon orbital station floorplan with nine interactive departments, Boss AI Core, CEO tower, perimeter fence, radar and telemetry.
- Department dossiers, agent details, capacity and efficiency indicators, simulated controls and mini-game preview.
- CEO daily report, owner approval queue, revenue ledger, cyber-defense status and in-app builder sandbox.
- Local command chat and responsive desktop, tablet and mobile navigation.
- Demo-only interactions. No payment processing, external messaging, API credentials, marketplace connections or real revenue are handled. Demo data is separate from verified revenue.

## Safety note

This is a front-end prototype. Values are simulated in the browser; it does not connect to AI services or run background agents. External actions are not implemented, and demo approvals do not represent real transactions.
